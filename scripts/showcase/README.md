# Showcase

The pieces on the homepage ("Made here") are generated by the club itself.

- `showcase.json` is the manifest: one entry per piece with its model, prompt
  and seed.
- `generate.py` runs the manifest against a saved deployment, titles each
  result, makes it public, files it in the "Showcase" collection and, with
  `--static`, writes web-sized copies and `index.json` to
  `frontend/public/showcase/`, which the homepage reads.

```bash
# once: save a deployment (the key is read from stdin, never from argv)
python3 integrations/skills/inference-club/scripts/ic.py instance add local --base-url http://localhost:8101

scripts/showcase/generate.py --instance local --static        # make everything, refresh the static files
scripts/showcase/generate.py --instance production            # the same seeds on another deployment
scripts/showcase/generate.py --instance local --only great-wave --force
```

Because every piece has a fixed seed, a second run should give the same
output. `index.json` records a SHA-256 of each raw result and a later run says
whether its output is `identical to recorded` or `DIFFERS from recorded`.
Identical bytes are expected on the same hardware and model build; across
different GPUs they are not guaranteed.

Items whose service is offline fail and are skipped; rerun later to fill them
in. `--static` needs `cwebp` and `ffmpeg` on `PATH`.
